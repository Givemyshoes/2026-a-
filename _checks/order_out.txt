==============================================================
一个时间步的内部流程
==============================================================

【备料 1】循环 21 次，把 21 个点的 rho/cp/kk 都算出来
   -> 调用 prop 的次数累计 = 21

【用料 1】温度三个公式，直接取 rho[r] cp[r] kk[r]
   -> 调用 prop 的次数还是 21 （公式里只是"取"，没有再调用）

【备料 2】再用【刚更新的】温度，算 21 个点的 D
   -> 调用 prop 的次数累计 = 42

【用料 2】水分三个公式，直接取 D[r]
   -> 调用 prop 的次数还是 42

==============================================================
结论：一个时间步共调用 prop 42 次 = 21(备温度料) + 21(备水分料)
      跑到 20 万步就是 8400000 次调用
==============================================================

对比：如果"不备料"，直接在公式里调用函数，会长这样：

    T[t+1][r] = T[t][r] + ( 0.5*(prop(problem,C[t][r],T[t][r])[2]
                                + prop(problem,C[t][r+1],T[t][r+1])[2])
                            * ... ) / ( prop(problem,C[t][r],T[t][r])[0]
                                      * prop(problem,C[t][r],T[t][r])[1] * ...)
    ...又长又慢，同一个点的物性被反复算好几遍

所以：先备料、后用料，是"图省事 + 图快"。
